Load Bank-2 (LB2)

Panel load used for aggregation / throttle.

Soft upper limit for LB2 commanded current. Actual amps also cannot exceed what the selected channels can deliver (all four ≈ 83 A; CH3+4 alone ≈ 42 A).
LB2 load channels
Enable only the channels that are physically connected for this run. Load steps are applied only on checked channels. Pick 120 V or 240 V per enabled channel.
Pause after the EV enters Charge before applying panel load, so the pilot settles first.
Delay between each step-wise LB2 current increase (aggregate) or decrease (recover).
How many amps to raise or lower LB2 commanded current on each step.
On: step LB2 up until the panel throttles (and optionally raise the ceiling if duty stays >10%). Off: fixed open-loop ramp to the max above.
Phase timing
Optional pause between major pipeline stages only (after capture, after boot ready, before recover, etc.). Does not insert delays between pilot watch → connect → charge, and does not control LB2 step timing.

 JAMA Test (EV + gateway)

          

            Runs advertise / comms JAMA cases only. Starts SBX/UART capture, verifies SBX comms,
            then runs selected cases. Requires EV Simulator in Charge mode and gateway SSH.
            At start, mutable values (user-max, seriald, pilot, relay) are noted; on any failure they are restored.
            Gateway commands print live in the activity log. Does not use Load Bank-2.

 Gateway Access

            

            Required for one-click runs (precheck before pipeline). Preferred:
            ssh -F ~/.ssh/span/<GATEWAY_SERIAL>/spanssh-config <GATEWAY_SERIAL>
            (no long-term CA cert). Set GATEWAY_SERIAL in config.env.
            Legacy: GATEWAY_SSH_HOST + cert/password.
